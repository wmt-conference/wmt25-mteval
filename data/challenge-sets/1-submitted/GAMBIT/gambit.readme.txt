Description:
This challenge set evaluates gender bias in machine translation (MT) quality estimation (QE) metrics using an extended version of the GAMBIT dataset (Gender-AMBIguous occupaTions). The original GAMBIT dataset contains occupation-related texts with gender-ambiguous expressions in English, covering the full ISCO-08 occupational classification.
For this challenge, we expand the dataset to include three source languages where the occupational terms are gender-neutral or gender-ambiguous and 11 target languages with grammatical gender. Each source sentence was translated into two target-language versions: one using the masculine form and one using the feminine form of the occupational terms. To ensure a fair comparison, the translations into masculine and feminine forms were crafted to be as similar as possible, with the only differences being those strictly necessary to reflect grammatical gender (e.g., changes in nouns, adjectives, pronouns, etc.). This controlled setup minimizes confounding factors and isolates gender as the only variable of interest. All texts were automatically generated using Claude v3.5.
The goal of this challenge set is to test whether QE metrics behave fairly when evaluating translations of gender-ambiguous occupational terms. A bias-free QE metric is expected to assign identical or nearly identical scores to both the masculine and feminine translations of a gender-ambiguous source sentence. By design, the challenge set enables fine-grained analyses per occupation.
This challenge set builds directly on the GAMBIT dataset introduced in Menis Mastromichalakis et al., 2025 (https://arxiv.org/abs/2503.04372). 

Source Languages: English, Turkish, Finnish
Target Languages: Spanish, Arabic, Czech, Icelandic, Russian, Serbian, Ukrainian, Greek, Portuguese, Italian, and French. 

Each language pair contains:
- Source text with gender-ambiguous occupation mentions
- Two hypotheses: one with masculine forms (hyp-1), one with feminine forms (hyp-2) of occupations
- Metadata including ISCO occupation codes and document IDs

All files are aligned, meaning that each row in all files (in metadata it's +1 due to the headers) corresponds to the same text in the respective language. 
From the original 9805 texts of GAMBIT, we removed those that couldn't be translated into 2 gender forms in any of the languages so as to make sure that the 2 gender variations indeed differ, and keep all the files aligned. This left us with 8771 texts.  

Note: All texts have been cleaned to remove newlines and ensure one sentence per line for proper alignment.
